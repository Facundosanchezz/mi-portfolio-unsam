📐 Matemática Inicial: Funciones y Límites

Apunte creado por Facundo Sanchez para la comunidad de la UNSAM.

1. Concepto de Límite

El límite describe el comportamiento de una función a medida que su entrada se acerca a un cierto valor. Es la base del cálculo diferencial.

2. Ejemplo Práctico en Python

Podemos aproximar un límite numéricamente usando NumPy. Aquí un ejemplo de cómo evaluar la función f(x) = (x² - 1) / (x - 1) cuando x tiende a 1:

import numpy as np

def f(x):
    return (x**2 - 1) / (x - 1)

# Evaluamos valores muy cercanos a 1
x_vals = np.array([0.9, 0.99, 0.999, 1.001, 1.01, 1.1])
print("Aproximación del límite:", f(x_vals))

3. Tips para el Parcial

  • Siempre factorizar antes de evaluar (como en el ejemplo de arriba, es una diferencia de cuadrados).
  • Recordar los límites notables trigonométricos.
  • Practicar con la calculadora solo para verificar, no para resolver.
