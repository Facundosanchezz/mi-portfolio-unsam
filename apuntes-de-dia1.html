🧪 Validación de Datos: Del Laboratorio al Pipeline

Primer paso de mi ruta autodidacta en Data Engineering + Data Science

🎯 Contexto real: Un laboratorio registra mediciones, pero algunas son incorrectas. Antes de calcular estadísticas, necesitamos distinguir los datos confiables de los defectuosos. Esto importa en dos mundos: un pipeline puede automatizar errores, y un modelo estadístico puede dar resultados engañosos si recibe datos inválidos.

1. El problema

Imaginá que recibís una lista de mediciones de un instrumento de laboratorio:

mediciones = [1.2, 1.4, 1.3, None, 1.5, "error", 1.1, 1000, 
              float("nan"), float("inf")]

Algunas son números válidos, otras son errores de formato, y otras son números pero fuera del rango permitido por el instrumento.

2. La solución: clasificar antes de rechazar

En lugar de simplemente descartar lo que "no sirve", vamos a clasificar cada error para entender qué está pasando con los datos.

Función de clasificación

import math

MINIMO = -5.0
MAXIMO = 5.0

def clasificar_medicion(valor):
    # 1. Comprobar el formato
    if isinstance(valor, bool) or not isinstance(valor, (int, float)):
        return "error de formato"
    
    # 2. Comprobar si es finito
    if not math.isfinite(valor):
        return "número no finito"
    
    # 3. Comprobar el rango permitido
    if not MINIMO <= valor <= MAXIMO:
        return "fuera de rango"
    
    return "válida"
💡 Concepto clave: math.isfinite()
En Python existen valores numéricos especiales como float("nan") (Not a Number) e float("inf") (infinito). math.isfinite() devuelve True solo si el número es finito, excluyendo estos casos especiales que romperían cualquier cálculo.

3. Generando el informe de calidad

Ahora recorremos las mediciones, las clasificamos y generamos un reporte:

validas = []
conteo_errores = {
    "error de formato": 0,
    "número no finito": 0,
    "fuera de rango": 0
}

for medicion in mediciones:
    categoria = clasificar_medicion(medicion)
    if categoria == "válida":
        validas.append(medicion)
    else:
        conteo_errores[categoria] += 1

# Informe
print(f"Total recibidas: {len(mediciones)}")
print(f"Válidas: {len(validas)}")
for tipo, cantidad in conteo_errores.items():
    print(f"  - {tipo}: {cantidad}")

if validas:
    promedio = sum(validas) / len(validas)
    print(f"Promedio: {round(promedio, 3)}")

Salida del programa:

Total recibidas: 10
Válidas: 5
- error de formato: 2
- número no finito: 2
- fuera de rango: 1
Promedio: 1.3

4. Lo que aprendí

  • Separación de responsabilidades: la función clasifica, el código principal reporta. Cada cosa en su lugar.
  • Diccionarios como contadores: mucho más escalable que tener una variable por cada tipo de error.
  • El patrón validar → clasificar → reportar: es el corazón de un pipeline de calidad de datos real.
  • Defensa contra datos inválidos: calcular un promedio con un NaN o un 1000 destruiría los resultados.
🔗 Conexión con Física Médica:
En un laboratorio de dosimetría (radioterapia), los límites MINIMO y MAXIMO no se eligen arbitrariamente: representan el rango físico válido del instrumento. Un valor fuera de rango puede indicar un sensor dañado o una medición corrupta. Este mismo código podría usarse para validar lecturas de cámaras de ionización, detectores de radiación, etc.
